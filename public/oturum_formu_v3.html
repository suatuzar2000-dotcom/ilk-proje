⚙️  Yönetici Ayarları — Google Apps Script URL

Formun doğrudan Sheets'e yazabilmesi için Google Apps Script web uygulaması URL'sini girin.
URL girilmezse veriler CSV olarak indirilir — siz Sheets'e manuel yapıştırırsınız.

Apps Script kodu (script.google.com → Yeni proje):

function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const sheet = SpreadsheetApp.openById(data.sheetId).getActiveSheet();
  data.rows.forEach(row => sheet.appendRow(row));
  return ContentService.createTextOutput(JSON.stringify({status:'ok'}))
    .setMimeType(ContentService.MimeType.JSON);
}
